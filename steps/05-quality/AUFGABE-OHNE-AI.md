# Übung Block 5 · Ohne AI-Tool – Erkundung der Bahn-Werkzeuge

**Ziel:** Ihr lernt drei Werkzeuge kennen, mit denen ihr ein echtes Projekt nicht bei null beginnt. Alles läuft im
Browser, ohne Installation. Die Links stehen auf der Folie **„Übung 5“** (DB-intern).

## 1. DB API Portal: Woher kommen echte Daten?

- Sucht eine API mit Bahnhofs- oder Fahrplandaten. Was braucht ihr, um einen Zugang zu bekommen?
- Stöbert: Welche andere API würde zu eurer Arbeit passen?
- Bonus: Wo gehören Zugangsdaten in einem echten Projekt hin? (Tipp: nie in den Browser-Code)

## 2. Referenzimplementierung: Wie sieht ein fertiger Starter aus?

Öffnet die Demo einer Referenzimplementierung, z. B. Vue:

- Bedient sie **nur mit der Tastatur**. Gibt es einen Skip-Link? Seht ihr immer, wo der Fokus ist?
- DevTools → **Elements**: Welche `db-…`-Komponenten erkennt ihr aus unserem Workshop wieder?
- DevTools → **Lighthouse** → nur „Accessibility“ → „Analyze page load“. Welche Punkte findet es?

## 3. MCP-Server: Welches Bahn-Wissen kann eine AI nutzen?

Schaut in die Liste **Awesome Bahn MCP Servers** und den **AI Catalog** im Developer Portal:

- Welcher Server würde euch im Alltag helfen?
- Was müsst ihr laut Hinweis in der Liste tun, bevor ihr einen Server nutzt?
